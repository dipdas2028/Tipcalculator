💰 Tip Time – Android App

An Android app built with Kotlin and Jetpack Compose that helps you quickly calculate restaurant tips, split the bill among people, and round up totals if desired.

✨ Features

🧮 Tip Calculator – Enter your bill amount and select/customize tip percentage

👥 Bill Splitting – Divide the total among multiple people

🔄 Rounding Option – Toggle rounding up the tip amount

🎨 Modern UI – Built with Jetpack Compose and Material 3

💾 State Saving – Uses rememberSaveable to preserve inputs on configuration changes
